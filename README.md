# tech-talk-study

관심 있는 기술 주제를 정리해 발표하고, 다음 주에 다른 멤버들이 같은 주제를 각자의 시선으로 조사해 공유하는 **2주 사이클 발표형 스터디**입니다.

## 진행 방식

| 주차 | 내용 |
| --- | --- |
| **1주차 · 발표** | 발표자가 현업 경험, 기술 블로그, 논문, 책 등에서 관심 있는 주제를 골라 정리하고 발표 |
| **2주차 · 확장 리서치** | 나머지 멤버들이 해당 주제와 관련해 현업·기술 블로그·논문·책 등에서 보거나 경험한 내용을 조사해 공유 |

## 디렉터리 구조

```
tech-talk-study/
├── README.md
└── 00_주제/
    ├── 발표자_github_id.md          # 발표 자료
    └── research/
        ├── 조사자_github_id.md      # 멤버별 확장 리서치
        ├── 조사자_github_id.md
        └── ...
```

## 규칙

- 주제 폴더명: `{순번 2자리}_{주제}` (예: `02_Kafka컨슈머튜닝`)
- 발표 자료는 `{주제 폴더}/{발표자 github id}.md`
- 확장 리서치는 `{주제 폴더}/research/{조사자 github id}.md`, 출처(링크·도서·논문)를 꼭 남기기
- 발표 주제가 정해지면 위 일정 표의 `TBD`를 업데이트
