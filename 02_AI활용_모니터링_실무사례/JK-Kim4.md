## 5. 사례

### 사례 1 · 9/21 · 옛 BI 도구: 193일 동안 접속 0

- **트래픽**: 이관 뒤 193일 접속 0. 남은 960GB는 일부러 버린 쿼리 캐시
- **용도 확인**: 700GB 디스크 = 옛 메타 DB. git 최초 커밋의 구성으로 확인
- **차단 테스트**: 주말 동안 접속 차단, 문의 0건
- **지운 것**: DB 1대 (1,200GB), 서버 2대 + 디스크 708GB, 스냅샷 2장
- **효과**: 월 −$250 (청구서 기준)

### 사례 2 · 10/1 · 레거시 로드밸런서: 주인 없는 입구 4개

- **관리 주체**: 없어진 옛 클러스터 소유. 지금 클러스터는 다시 만들지 않음
- **차단 테스트**: 막고 2시간마다 8번 점검, 요청·연결 0
- **남은 요청**: 옛 배포 도구로 가는 웹훅. 막기 전부터 이미 실패(504)
- **지운 것**: 로드밸런서 4개, 타깃그룹 121개, 보안그룹 7개
- **효과**: 월 −$85 (시간 요금 + 공인 IP 6개)

### 사례 3 · 10/29 · EKS: 오래된 버전에 붙던 추가 요금

- **원인**: 1.31 표준 지원 종료 → 연장 지원 요금 (하루 약 $14, 표준은 약 $2.4)
- **결정**: 강제 자동 업그레이드 전에 1.36까지 하룻밤에 한 번에
- **확인**: 10/29부터 연장 지원 요금 $0
- **바꾼 것**: 버전 1.31 → 1.36, 노드 그룹 교체, 컨트롤러 6종 교체
- **효과**: 월 −$360 (8월 $446 → 11월 약 $72)

## 6. 지우지 않은 자원, 비용과 무관한 작업

| 구분 | 내용 |
| --- | --- |
| 보류한 자원 | 주인 없는 보안그룹 1개. IaC 관리 표시가 있지만 코드 위치를 모름 → 지우면 기록과 실제가 어긋남, 보관 비용 0 |
| 보안·유지보수 작업 | 옛 캐시 서버 → 서버리스 전환, 서버리스 함수 81개 → 12개. 비용은 거의 그대로 |

## 7. 예상과 달랐던 다섯 가지

1. 옛 서버에 종료 방지가 걸려 있음 — 11대 중 이 한 대만
2. 여러 대 종료 요청이 원자적이지 않음 — 한 대 거부, 한 대는 종료
3. DB 삭제 후 자동 스냅샷이 약 3분간 목록에 남음 — 삭제 판정은 자동 백업 목록이 비었는지로
4. 로드밸런서 보안그룹은 콘솔로 고치면 되돌아감 — 쿠버네티스 컨트롤러가 관리하므로 그쪽 설정으로만 변경
5. DB 로그 급감 → 고장 의심 — 원인은 9/30 상품 서버 개선 (매분 약 2,800건 행 전체 저장 → 바뀐 상태만 저장)
